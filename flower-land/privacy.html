2. 구글 로그인과 구글 드라이브

구글 로그인은 고르는 기능이에요 (⚙️ 설정 › 💾 저장 › ☁️ 구글 드라이브). 로그인하지 않아도 모든 기능을 쓸 수 있어요.

  • 요청하는 권한
    • https://www.googleapis.com/auth/drive.appdata — 드라이브에 이 앱만 쓰는 숨김 폴더를 만들고 그 안의 정원 파일만 읽고 써요. 여러분 드라이브의 다른 파일 · 폴더는 보지도 고치지도 않아요.
    • openid · email · profile — 설정 화면에 로그인한 이메일 주소를 보여 주는 데만 써요. 처음 로그인한 날은 첫 방문 칭호를, 「구름 정원사」를 받은 때는 로그인 보상(칭호 · 장식)을 다른 기기 · 새 정원에 이어 붙이는 데 써요 (보상의 얻는 연출은 계정마다 한 번).
  • 언제 저장하나요 — 달이 바뀔 때 · 칭호를 얻을 때 · 앱을 닫거나 다른 탭으로 갈 때 · "지금 저장"을 누를 때 (너무 잦지 않게 5분 간격). 다른 기기에서 저장한 정원이 있으면 바꾸기 전에 알려 드리거나 어느 정원을 쓸지 물어봐요.
  • 어디서 처리하나요 — 로그인과 드라이브 저장은 모두 여러분 브라우저와 구글 사이에서만 일어나요. 운영자의 서버는 없고, 구글 계정 정보 · 접근 토큰 · 정원 파일을 운영자가 받지 않아요.
  • 접근 토큰 — 구글이 주는 접근 토큰(로그인 열쇠)은 약 1시간 뒤 끝나요. 끝날 때까지만 이 브라우저 저장소에 보관해서 새로고침해도 다시 로그인하지 않아도 되고, 끝나거나 로그아웃하면 바로 지워요. 정원 저장 · 💾 파일 · 드라이브 파일에는 넣지 않고 운영자에게 보내지 않아요. 끝난 뒤에는 화면을 처음 누를 때 구글에서 다시 받아요 (구글 창이 잠깐 열렸다 닫힐 수 있어요). 안 되면 ☁️를 한 번 눌러 다시 연결하면 돼요 (그동안에도 정원은 이 브라우저에 계속 저장돼요).
  • 로그아웃 — 이 브라우저에서 드라이브 저장을 멈추고, 접근 권한을 구글에 돌려줘요. 이 브라우저의 정원과 드라이브의 정원 파일은 그대로 남아요.
  • Google API 사용자 데이터 정책 준수 — 도리의 정원이 Google API에서 받은 정보를 쓰고 다른 앱으로 옮기는 방식은 제한적 사용(Limited Use) 요구 사항을 포함한 Google API 서비스 사용자 데이터 정책을 따라요. 받은 정보는 정원 저장 · 불러오기와 로그인 표시에만 쓰고, 광고에 쓰거나 다른 사람에게 넘기거나 팔지 않으며, 사람이 열어 보지 않아요.

3. 운영자에게 보내는 정보

없어요. 도리의 정원은 정적 웹 페이지(GitHub Pages)로만 배포되고, 진행 · 로그인 정보를 운영자에게 보내는 코드가 없어요. 광고 · 분석(애널리틱스) · 오류 수집 도구도 쓰지 않아요.

4. 다른 곳에 접속하는 경우

  • GitHub Pages — 페이지를 내려받을 때 호스팅하는 GitHub이 접속 기록(IP 주소 · 브라우저 정보 등)을 남길 수 있어요. GitHub 개인정보처리방침을 따라요.
  • Google Fonts — 글꼴(주아 · 고운바탕 · IBM Plex)을 불러오려고 fonts.googleapis.com · fonts.gstatic.com에 접속해요. 이때 IP 주소 · 브라우저 정보가 구글에 전달될 수 있어요. Google Fonts 개인정보 안내를 따라요.
  • 구글 로그인 · 드라이브 — ⚙️ 설정을 열면 로그인 단추를 위해 구글 로그인 스크립트(accounts.google.com)를 불러와요. 로그인하면 구글 로그인 창, 드라이브 API(www.googleapis.com)에 접속해요. Google 개인정보처리방침을 따라요.

5. 쿠키

도리의 정원은 쿠키를 만들지 않아요. 구글 로그인을 쓰면 구글이 로그인 창에서 자기 쿠키를 쓸 수 있어요.

6. 지우는 방법 · 여러분의 권리

  • 브라우저의 정원 — 1년차 동안은 설정 › 🌱 정원 › 처음부터 다시 시작, 언제든 브라우저 설정에서 이 사이트의 데이터 삭제.
  • 내려받은 저장 파일 — 기기에서 파일을 지우면 돼요.
  • 구글 드라이브의 정원 — 구글 드라이브 › 설정 › 앱 관리에서 "도리의 정원"의 숨겨진 앱 데이터 삭제, 그리고 구글 계정 › 타사 앱 연결에서 연결을 해제하면 권한도 없어져요.
  • 운영자는 여러분의 정보를 갖고 있지 않아서 대신 열람 · 정정 · 삭제해 드릴 정보가 없어요. 궁금한 점은 아래 연락처로 물어봐 주세요.

7. 어린이

도리의 정원은 누구나 쓸 수 있는 놀이예요. 구글 계정의 나이 제한은 구글 정책을 따르고, 만 14세 미만이 구글 로그인을 쓰려면 보호자 동의가 필요할 수 있어요. 로그인 없이도 모든 기능을 쓸 수 있어요.

8. 안전

정원 진행은 여러분 기기 안에만 있어요 (구글 로그인을 하면 여러분 드라이브에도). 같은 기기 · 같은 브라우저를 쓰는 다른 사람은 정원을 볼 수 있으니, 공용 기기에서는 다 쓴 뒤 사이트 데이터를 지워 주세요.

9. 바뀔 때

저장하는 정보나 쓰는 곳이 바뀌면 이 페이지를 고치고 맨 위 날짜를 바꿔요. 중요한 변경은 앱 안에서도 알려 드려요.
