도리의 정원 (Dori's Garden) · 시행일 2026-10-17

  • 운영자는 서버를 두지 않고, 여러분의 정보를 받아 보관하지 않아요.
  • 정원 진행은 여러분 브라우저 안에 저장돼요.
  • 구글 로그인 · 드라이브 저장은 아직 없어요. 나중에 켤 기능이라, 아래에서 준비 중 표시가 붙은 내용은 그 기능을 켠 날부터 적용돼요. 그 전까지 도리의 정원은 구글 계정에 접근하지 않아요.
  • 광고 · 분석 도구 · 추적 쿠키를 쓰지 않아요.
  • 글꼴을 불러올 때만 Google Fonts에 접속해요 (아래 4번).

2. 구글 로그인과 구글 드라이브 준비 중

아직 없는 기능이에요. 지금 도리의 정원에는 구글 로그인 단추가 없고, 구글 계정이나 드라이브에 접근하지 않아요. 아래 내용은 이 기능을 켠 날부터 적용되고, 그때 이 표시를 떼고 맨 위 시행일을 바꿔요.

기능이 생겨도 구글 로그인은 고르는 기능이에요. 로그인하지 않아도 모든 기능을 쓸 수 있어요.

  • 요청하는 권한
    • https://www.googleapis.com/auth/drive.appdata — 드라이브에 이 앱만 쓰는 숨김 폴더를 만들고 그 안의 정원 파일만 읽고 써요. 여러분 드라이브의 다른 파일 · 폴더는 보지도 고치지도 않아요.
    • openid · email · profile — 설정 화면에 "○○@gmail.com으로 로그인됨"을 보여 주고, 처음 로그인한 날을 기록하는 데만 써요.
  • 어디서 처리하나요 — 로그인과 드라이브 저장은 모두 여러분 브라우저와 구글 사이에서만 일어나요. 운영자의 서버는 없고, 구글 계정 정보 · 접근 토큰 · 정원 파일을 운영자가 받지 않아요.
  • 접근 토큰 — 구글이 주는 접근 토큰(약 1시간)은 브라우저 메모리에만 두고 저장하지 않아요.
  • Google API 사용자 데이터 정책 준수 — 도리의 정원이 Google API에서 받은 정보를 쓰고 다른 앱으로 옮기는 방식은 제한적 사용(Limited Use) 요구 사항을 포함한 Google API 서비스 사용자 데이터 정책을 따라요. 받은 정보는 정원 저장 · 불러오기와 로그인 표시에만 쓰고, 광고에 쓰거나 다른 사람에게 넘기거나 팔지 않으며, 사람이 열어 보지 않아요.

3. 운영자에게 보내는 정보

없어요. 도리의 정원은 정적 웹 페이지(GitHub Pages)로만 배포되고, 진행 · 로그인 정보를 운영자에게 보내는 코드가 없어요. 광고 · 분석(애널리틱스) · 오류 수집 도구도 쓰지 않아요.

4. 다른 곳에 접속하는 경우

  • GitHub Pages — 페이지를 내려받을 때 호스팅하는 GitHub이 접속 기록(IP 주소 · 브라우저 정보 등)을 남길 수 있어요. GitHub 개인정보처리방침을 따라요.
  • Google Fonts — 글꼴(주아 · 고운바탕 · IBM Plex)을 불러오려고 fonts.googleapis.com · fonts.gstatic.com에 접속해요. 이때 IP 주소 · 브라우저 정보가 구글에 전달될 수 있어요. Google Fonts 개인정보 안내를 따라요.
  • 구글 로그인 · 드라이브 준비 중 (기능이 생긴 뒤 켠 경우) —Google 개인정보처리방침을 따라요.

5. 쿠키

도리의 정원은 쿠키를 만들지 않아요. 나중에 구글 로그인이 생겨 그걸 쓰면 구글이 로그인 창에서 자기 쿠키를 쓸 수 있어요.

6. 지우는 방법 · 여러분의 권리

  • 브라우저의 정원 — 설정 › 🌱 정원 › 처음부터 다시 시작, 또는 브라우저 설정에서 이 사이트의 데이터 삭제.
  • 내려받은 저장 파일 — 기기에서 파일을 지우면 돼요.
  • 구글 드라이브의 정원 준비 중 (기능이 생긴 뒤 켠 경우) —구글 드라이브 › 설정 › 앱 관리에서 "도리의 정원"의 숨겨진 앱 데이터 삭제, 그리고 구글 계정 › 타사 앱 연결에서 연결을 해제하면 권한도 없어져요.
  • 운영자는 여러분의 정보를 갖고 있지 않아서 대신 열람 · 정정 · 삭제해 드릴 정보가 없어요. 궁금한 점은 아래 연락처로 물어봐 주세요.

7. 어린이

도리의 정원은 누구나 쓸 수 있는 놀이예요. 지금은 로그인이 없어요. 나중에 구글 로그인이 생기면 구글 계정의 나이 제한은 구글 정책을 따르고, 만 14세 미만이 구글 로그인을 쓰려면 보호자 동의가 필요할 수 있어요. 그때도 로그인 없이 모든 기능을 쓸 수 있어요.

8. 안전

정원 진행은 여러분 기기 안에만 있어요 (구글 드라이브 저장이 생기면 여러분 드라이브에도). 같은 기기 · 같은 브라우저를 쓰는 다른 사람은 정원을 볼 수 있으니, 공용 기기에서는 다 쓴 뒤 사이트 데이터를 지워 주세요.

9. 바뀔 때

저장하는 정보나 쓰는 곳이 바뀌면 이 페이지를 고치고 맨 위 날짜를 바꿔요. 중요한 변경은 앱 안에서도 알려 드려요.
