2. ⚙️ 설정에서 "큰 글씨"를 켜자 글자와 둘레 단추가 커져 손가락으로 누르기 쉬워진다. 🔜 (P28-01) ← 새 후보 1
3. 반짝이는 꽃을 눌러 💧 물을 주고, 상태창에서 "다음 달에 피어요"를 읽는다. ✅ (P13-01, P14-01)
4. 핀 꽃을 🧺 거두자 꽃잎이 제다실로 간다는 알림이 뜬다. ✅ (P12-05)
5. 사흘을 못 열었다가 다시 열어도 꽃은 시들지 않고 그대로 있다. ✅ (P06-02, P25-00)

2. ⚙️ 설정에서 "느긋하게 보기"를 켜자 퀘스트 줄 · 주문 쪽지 · 점수 표시가 숨는다. ✅ (P28-02) M1 10-28 ← 새 후보 2
3. 목마른 꽃 몇 송이에 물을 주고 잡초를 뽑는다. ✅ (P13-01, P13-02)
4. 핀 꽃을 거두고, 꽃방에 널어 둔다. ✅ (P12-05, P12-07)
5. 알림은 꺼 두었으니 다음 날까지 아무 알림도 오지 않는다. ✅ (P11-02)
6. "느긋하게 보기"를 켜도 칭호를 얻으면 조용히 도감에만 쌓인다. ✅ (P28-02) M1 10-28 ← 새 후보 2

4. 장식을 사서 꽃 옆에 놓는다. ✅ (P17-16)
5. 다음 주말에 열자 심은 꽃이 피어 있어 거둔다. ✅ (P06-02, P25-00)

### 04 남궁별 — 그림처럼 꾸미고 해마다 모으기
