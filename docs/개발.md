## 로컬에서

Node.js 24 이상 (빌드 도구 · 패키지 없음).

```bash
node flower-land/serve.js
```

(포트를 바꾸려면 `node flower-land/serve.js flower-land 5180`)

→ http://localhost:5173 . **localhost에서만** ⚙️ 설정에 개발용 ⏩ 시간 묶음(배속 · 다음 달 건너뛰기)이 보여요.

```bash
node flower-land/tests/run.js
```

엔진 테스트 81개 파일(`tests/*.test.js` — 기능마다 하나, 최근 것은 `p40` ~ `p60`처럼 P 번호). 엔진 규칙을 Node에서 돌리고, `manual` · `p46` · `p59` · `p60` 같은 몇 개는 화면 코드를 글자로 읽어 확인해요. `mail.test.js`는 실제 `mail.json`을 검사해요. 배포 워크플로도 이걸 먼저 돌리고, 실패하면 배포하지 않아요. 하나만 돌리려면 `node flower-land/tests/p60.test.js`.

**엔진 스냅숏 (P66)**: `snapshot.test.js`가 `tools/engine-snapshot.js`의 글(공개 이름마다 값 해시 · `MIGRATIONS` 보정 이름 · 새 정원 · 옛 저장 옮긴 결과 · 저장 파일 해시)을 `tests/engine-snapshot.txt`와 견줘요. 엔진을 나누거나 옮기기만 할 땐 그대로여야 하고, 공개 이름 · 보정 줄을 더하는 등 일부러 바꿨으면 `node flower-land/tools/engine-snapshot.js --write`로 다시 쓰고 diff에 바꾼 것만 있는지 봐요. 엔진 글자를 구역으로 잘라 읽는 테스트(`p53` · `visitor` · `yearly`)는 `tests/engine-src.js`의 `source()`로 읽어요(조각으로 나뉘어도 이은 글자). `globals.test.js`는 엔진 최상위 이름과 화면 파일 최상위 이름이 같은 전역 이름 공간에서 겹치지 않는지 V8(vm)로 펼쳐 봐요.

**🌱 정원 등급 (P28-05-01)**: 정원에서 한 일에 경험치를 주려면 `E.addXp(st, 종류, n, ctx)` (종류는 `E.XP` — 새로 생기면 표에 더하고 시뮬 주마다 등급 표를 다시 봐요). 돈을 주고 사는 것에는 주지 않아요(P17-14). 오르면 `ctx.onGrade` 이벤트(화면은 `E.gradeAlerts`로 알림), 읽기는 `E.gradeOf(st)` · 화면은 `E.gradeView` (도감 등급 쪽) · `E.gradeBadge` (위 막대).

**🐢 느긋하게 보기 (P28-02)**: 새 숫자 · 목표 화면(정원 등급 · 그래프 · 주간 목표 · 효율 표 …)을 만들면 `E.slowView(st)`가 참일 때 숨겨요. 숨길지는 이 함수 하나만 보고, 얻는 규칙은 바꾸지 않아요. 📈 해마다 그래프는 숫자 · 견줌만 빼고 모양은 남겨요(P28-07-02).

**🗓️ 주간 목표 (P28-09)**: 목표 종류는 엔진 `WEEKLY` 표(쉬움 · 보통 · 어려움 · `ev` 어떤 일에 오르는지 · `fam` 같은 주에 한 줄 · `open` 그 정원이 연 기능인지). 새 행동이 목표에 들어가야 하면 그 엔진 함수에서 `E.weekNote(st, ev, info, n, ctx)`를 부르고 표에 한 줄 더해요. 돈을 내고 끝나는 일은 목표로 넣지 않아요(P17-14). 화면은 `weeklyView` · `weeklyAwayLine`만 읽고, 느긋하게 보기면 null이에요. DEV ⏩ 시간 묶음에 "🗓️ 하나 끝 · 다음 주".

**🐝 곤충 · 🧺 장치 (P28-10 · P39)**: `DECOS[k].auto`가 놓으면 일하는 것(창고에선 쉼 · 새 철에도 제자리), 그중 `insect`가 곤충 일곱(`INSECTS` = 장식 키 → 🌼 기르기 칸, 데려오기는 곤충농장 카드 · `need` 정원 등급 · 한 종류에 하나 `one`). 곤충은 놓은 자리 둘레 `insectR(st, 키)`칸(기르면 2 → 4 → 6, P61-01)의 꽃에만 — `onSlot`에서 꽃잠이 아닌 달이 끝날 때 `insectTick`이 🐌 물 · 🐞 잡초 · 🪱 비료 · 🐛 가지치기(`INSECT_CARE` — 남은 효과가 한 달보다 짧으면 손으로 준 것과 같은 시간으로, 🪱도 달마다(P76-01 — 예전 `WORM_EVERY` 석 달은 없앰), 손 돌봄 비료 덤 없음 · P77-B 🐞 호미 · 🪱 비료 · 🐛 가위를 포기마다 씀(`INSECT_SUPPLY` · `insectTake`: 없으면 가방 재료로 `insectCraft`, 재료가 없으면 기력으로 `insectDig`(💎 · 계단 빼고), 그래도 없으면 쉼 — 카드 까닭 `insectShort`) · 곤충 돌봄도 주간 목표 `weekNote` care(`INSECT_TOOL`)) → 🐜 거두기(`basketTick`, 둘레 핀 꽃 모두 · 변이 꽃 빼고) → 🧺 건조 선반(`rackTick`, 하나에 `SHELF_N` 4장). 🦋 나비는 거둘 때(`care` · `basketTick`의 `harvestYear` — 둘레 꽃의 그달 첫 수확에 꽃잎 +1 — P76-01부터 달마다(`f.bfm` 덤 받은 달), 예전 `f.hy` · `f.bfy` 해 단위는 안 씀), 🐝 꿀벌은 번식할 때(`propQuality(q, rng, half)` 깎임 절반 — 뽑는 수는 같음) + 꿀(`hiveTick` — P65-01 바로 📦 창고 `st.honey`로, 창고 꿀이 `hiveMax`병이면 쉼 · 🍵 꿀차는 `brew(…, honey)` · `honeyTeaValue`). 효과 한 줄은 `INSECT_LINE` · `insectLine`(P65-04 — 카드 · 정원 창 · 장식 desc · 넓히기 desc 모두). 🐜 개미는 손 수확 표시 `harvestKey` 대신 `antKey`(P65-03) — P72-01부터는 거두는 모든 길(손 · 개미 · 저장고)이 `pickFlower`로 꽃을 다시 다 자람으로 돌려요. ⚙️ 자동 건조기(P72-02 `autodryer`)는 놓여 있으면 `autoDryTick`이 제다실 꽃잎을 바로 꽃방에(장수 제한 없음 · 말린 꽃잎 칸으로 — 티백은 안 만듦) — 부르는 곳은 `flushPending` · `insectTick`(개미 다음 · 선반 앞) · advance 달 바뀐 뒤 · `takePantry` · `buyPetal`. 🫖 찻집 도우미는 `advance` 걸음마다 팔기 바로 앞(`helperTick`, 손님 자리 + `TEASTAND_KEEP` 2잔). 꽃 상태창 아이콘은 `insectsOn`, 곤충농장 카드는 `farmOf`. 손으로 다 할 때보다 더 벌지 않게(P17-14) 맞췄으니 값을 바꾸면 `insects.test.js` · `auto.test.js`와 시뮬 `--auto --insects=… --bonus all`을 다시 봐요(체크리스트 P39-13 표). "자리를 비운 동안"은 `autoStats` · `autoAwayLines`로 곤충 · 장치마다 한 줄(일지 종류 20 🐝). 4층이 열리면 `ladybugGift`로 🐞 한 마리(예전 🌿 숲 바람 `forestWeedTick`은 없앰).

## 디자인 규칙 (P57)

화면이 깨지지 않게(카드 밖으로 글자 · 단추가 나가거나 카드끼리 겹치지 않게) 지키는 것. 자세한 것은 `style.css` 맨 위 주석, 규칙 자체는 파일 맨 끝 「── 디자인 규칙 (P57)」 절.

- **토큰**: 간격 `--sp-1..8`(2 ~ 16px) · 모서리 `--r-sm` 12px 단추 · 칩 · 탭 / `--r-xl` 16px 카드 · 지도 틀 · 창 / `--r-pill` 10px 작은 칩 / `--r-xs` 6px / `--r-dot` 4px · 글자 `--fs-xs..2xl`(11 ~ 20 × `--u`, 큰 글씨면 같이 커짐) · 카드 최소폭 `--card-min-xs..xl`. 새 규칙은 이 값을 쓰고, 색은 있는 색 변수만
- **🍮 젤리 도트 (P89)**: `style.css` 맨 끝 「── 젤리 도트 (P89)」 절. 단추와 UI는 둥근 사각형, 도트 그림과 지도 칸은 네모 그대로. 단추는 면 + 아래 두께(inset 그림자)이고 누르면 `--press`만큼 내려가요(움직임 줄이기면 0). 돌봄 색은 `--k`를 `--jelly-base`에 `--jelly-a` · `--jelly-b`만큼 섞어요 — 낮 · 밤은 이 값만 바뀌어요. 주 단추 · 고른 탭 `--gold*`, 지도 위 단추 `--cream*`, 판 테두리 `--edge`(새 판 클래스는 그 절의 `:is` 목록에). 위 막대 · 탭 바탕은 나무 `--wood*`, 나무 위 글자 `--wood-ink` · `--wood-muted`. 글자는 바탕과 4.5:1 이상 — 글을 `opacity`로 흐리게 하지 않고 `--muted`로
- **단추 아이콘 (P89)**: `sprites.js` `UI_ICONS`(16×16)를 `uiImg(키, 배수)`로 넣어요. 지도 둘레 꽃 줄은 `--garland` CSS 무늬라 공유 그림엔 안 나와요
- **도트 크기**: 화면 그림은 16px의 배수만(`spriteImg` 크기 16 · 32 · 48 · 64…). 지도 칸도 `cell = 16 × k`(틀 폭에 가장 가까운 배수) — 틀보다 크면 `#mapScroll` 안에서 끌어서 봐요. 10px 넘게 끌면 칸 누르기가 아니에요. 지도와 함께 움직이는 것만 `.mapinner` 안에 둬요
- **카드 격자**: `repeat(auto-fill, minmax(min(100%, var(--card-min…)), 1fr))` — 칸 수를 고정하지 않음. 격자 트랙에 맨 `1fr`을 쓰지 않고 `minmax(0, 1fr)` (맨 `1fr`은 최소가 auto라 안의 nowrap 글자가 칸을 밀어냄)
- **카드**: 안이 grid인 한 칸 카드는 `grid-template-columns: minmax(0, 1fr)` — 새 카드 격자 · 한 칸 카드 클래스는 맨 끝 절의 목록에 더함
- **머리줄 · 단추 줄**: 이름 ↔ 값은 flex + wrap(값 nowrap, 넘치면 아래 줄) · 스테퍼 + 주 단추는 flex + wrap(단추 `flex: 1 1 auto; min-width: 0`, 글자 낱말 단위 줄바꿈)
- **검사**: `node flower-land/serve.js`로 띄우고 개발자 도구 콘솔에서

  ```js
  const s = document.createElement('script'); s.src = 'tools/layout-check.js'; document.head.append(s);
  layoutCheck()                 // 지금 화면 → { n, list }
  r = await layoutCheck.all()   // 탭 모두 + 화원 「모든 꽃」 + 창 4개
  layoutCheck.sum(r); layoutCheck.detail(r)
  ```

  카드 밖으로 나간 요소 · 형제 카드 겹침 · 가로 스크롤 · nowrap 글자 잘림(줄임표는 뺌)을 찾아요. 화면을 바꾸면 폭 375 · 768 · 1280 · 1536에서 0건인지 봐요 (꽃 · 장식이 찬 정원으로 — 빈 정원에선 안 보이는 카드가 많아요)

1. GitHub 웹에서 저장소 › `flower-land/mail.json` › ✏️(Edit this file)
2. 목록 `[ ]` 안에 편지 한 통 `{ … }`을 더해요 (여러 통이면 사이에 쉼표). 지난 편지는 지우지 말고 둬도 돼요 — 기간이 지나면 더 안 와요


알고 가는 것: 받은 기록(`st.mailGot`)은 정원 저장에 있어서 구글 드라이브로 이어 하면 두 번 안 받지만, 파일로 예전 저장을 불러오면 그 사이 받은 편지를 한 번 더 받을 수 있어요. 브라우저 캐시로 몇 분 늦게 보일 수 있어요. 받은 편지함이 가득(60통)하면 오래된 받은 편지부터 밀리고, 선물을 안 받은 📮 편지는 밀리지 않아요.

## 저장

- 진행은 브라우저 localStorage `flower-land-v3`에 자동 저장 (불러오기 직전 정원은 `flower-land-v3-undo`).
- ⚙️ 설정 › 💾 저장: `.json` 파일로 내보내기 · 불러오기 · 되돌리기. 형식은 `engine-save.js`의 `makeSave` / `parseSave` (`format: 1`, 해시로 깨짐 확인). 구글 드라이브 저장도 같은 형식을 써요.
- ☁️ 구글 드라이브 (P20-04 ~ 08): `flower-land/app-cloud.js` 맨 위 `GOOGLE_CLIENT_ID`에 Google Cloud 콘솔의 웹 클라이언트 ID를 넣으면 켜져요 (비어 있으면 ☁️ 화면이 모두 숨고 구글 스크립트도 안 불러요). 보안 비밀(secret)은 쓰지 않아요.
  - 클라이언트의 **승인된 JavaScript 원본**: `https://ff-1204.github.io` · `http://localhost:5173` (다른 포트로 확인하려면 그 주소도 더해요)
  - 드라이브 앱 전용 숨김 폴더에 `garden.json` · `garden.prev.json`, 요약(정원 이름표 · 저장한 때 · 계정 첫 방문 · 구름 정원사를 받은 때 `reward`)은 파일의 appProperties에. 이 기기 기록(이메일 · 마지막으로 맞춘 판 · 첫 방문 · reward)은 localStorage `flower-land-v3-cloud`, 토큰은 끝날 때까지(약 1시간)만 `flower-land-v3-cloud-token`에 (`E.cloudTokenUse`, 로그아웃 · 401 · 끝남 · 다른 계정이면 지움)
  - 로그인 보상 「구름 정원사」(P20-16): 드라이브와 맞춘 정원에 `E.giveCloudReward` — 연출은 계정마다 한 번(`reward`가 있으면 조용히). 덤 칭호 · 덤 장식은 `EXTRA_TITLE_KEYS` · `EXTRA_DECO_KEYS`라 칭호 수 · 꾸밈 도감 칸에 넣지 않음
  - 무엇을 쓸지(여러 기기)는 `E.cloudDecide`, 다른 정원인데 한쪽이 거의 새 정원이면 묻지 않음(`E.freshGarden` · `E.freshPick`), 저장 간격은 `E.cloudDue` (5분, 닫을 때 · 지금 저장은 바로)
